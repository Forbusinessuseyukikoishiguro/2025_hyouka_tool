📊 ダッシュボード（全メンバーの信号）

使い方： 全メンバーの総合信号を一覧します。赤信号が上に来るので、フォローが必要な人がすぐ分かります。メンバーは下のバーで追加・切替できます。

🗣 口頭理解度チェック

使い方： 設問ごとに レベル(Lv.1/3/5) と 信号 を記録します。 「最低限（必須）」にチェックした設問で赤を付けると、総合は自動的に赤信号になります（＝最低限が抜けている）。 事実（observ）と所感を分けてメモしましょう。

✍ 筆記試験

使い方： 設問ごとに配点と得点を入れると、合計と得点率（％）を自動計算します。 「最低限（必須）」設問で得点0なら、総合は赤信号になります。

🚦 総合判定

使い方： 口頭と筆記のスコアを、メンター設定の重みで合算 → 総合スコア・レベル・信号を判定します。 必須項目落ちがあれば、スコアに関係なく赤信号になります。判定後はメモを添えて記録できます。

⚙ メンター設定（しきい値・重み）

使い方： 信号やレベルの境界をメンター自身が設定できます。チーム・職位に合わせて調整してください。設定は全メンバー共通です。

🤖 AI講評（任意・APIあり版）

使い方： 選択中メンバーの評価をもとに、AIが講評文のたたき台を作ります。 APIキーはあなたが入力した時だけ使われ、Anthropic APIへ送信されます（既定では何も送りません）。 出力はあくまで下書き。事実確認とトーンの調整は必ず人が行ってください。
※ 送信先は api.anthropic.com のみ。評価データ（スコア・信号・所感）が送られます。個人を特定する不要な情報は入力しないでください。

💾 データ保管

使い方： 全メンバー・全設定をJSONで保存／復元できます。CSVで一覧を書き出すこともできます。保存先はあなたの端末だけです（外部送信なし）。データはブラウザにも自動保存されます。
